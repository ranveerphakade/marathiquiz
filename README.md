# 📚 मराठी प्रश्नमंजुषा (Marathi Quiz Application)
### इयत्ता ४ थी • शिष्यवृत्ती सराव (Class 4 • Scholarship Practice)

इयत्ता चौथीच्या विद्यार्थ्यांसाठी मराठी विषय शिष्यवृत्ती परीक्षेच्या तयारीसाठी एक सोपे, बालसुलभ व आधुनिक **Streamlit** वेब ॲप्लिकेशन.

---

## 🎯 मुख्य विभाग (Main Sections)

1. **🏠 Home (मुख्य पृष्ठ)**:
   - विषय: मराठी, इयत्ता: ४ थी, एकूण उपलब्ध प्रश्न संख्या (५१ प्रश्न).
   - **पूर्ण परीक्षा (Full Quiz)** आणि **सराव परीक्षा (Practice Quiz: ५, १०, २० प्रश्न)** पर्याय.
   - थेट परीक्षा सुरू करण्याचे बटण आणि स्वतंत्र **🤖 Quiz Bot** कडे जाण्याचे बटण.

2. **📝 Quiz (प्रश्नमंजुषा)**:
   - स्वच्छ व मोठी अक्षरे, प्रोग्रेस बार (`प्रश्न १ / १०`), घटक (Topic) टॅग.
   - ४ बहुपर्यायी पर्याय (MCQ).
   - `मागील प्रश्न (Previous)` आणि `पुढील प्रश्न (Next)` नेव्हिगेशन.
   - `st.session_state` मुळे निवडलेली उत्तरे सुरक्षित राहतात.
   - चालू प्रश्नावरून थेट `🤖 हा प्रश्न समजावून घ्या` पर्याय.

3. **🏆 Result (निकाल)**:
   - एकूण गुण, टक्केवारी, बरोबर/चुकीची/अनुत्तरित प्रश्नांची आकडेवारी व गुणवत्तेनुसार शेरा.
   - `पुन्हा परीक्षा द्या`, `चुकीचे प्रश्न पहा`, आणि `🤖 माझ्या चुका Quiz Bot कडून समजून घ्या`.

4. **❌ Wrong Answers (चुकीचे प्रश्न)**:
   - फक्त चुकलेल्या व अनुत्तरित प्रश्नांची यादी.
   - विद्यार्थ्याचे उत्तर, योग्य उत्तर आणि मूळ स्पष्टीकरण (`explanation`).
   - `🤖 हा प्रश्न Quiz Bot कडून समजून घ्या` बटण.

5. **🤖 Quiz Bot (स्वतंत्र अभ्यास मित्र)**:
   - **स्वतंत्र मुख्य पर्याय:** सायडबारमधून कधीही थेट उघडता येतो (परीक्षा देण्याची सक्ती नाही).
   - **दोन इनपुट पद्धती:**
     - **Option A (मुक्तपणे प्रश्न विचारा):** "हा प्रश्न समजावून सांग.", "माझे उत्तर का चुकले?", "मला hint द्या.", "सोप्या भाषेत सांगा."
     - **Option B (प्रश्न निवडा):** `questions.json` मधील सर्व ५१ प्रश्नांमधून ड्रॉपडाउनद्वारे प्रश्न निवडणे.
   - **Hint Mode:** थेट उत्तर न सांगता विचार करायला लावणारा छोटा सुगावा (Clue) देणे.
   - **Explanation Mode:** योग्य उत्तर, त्याचे कारण आणि साधे उदाहरण देणे.

## 📁 प्रकल्प रचना (Project Structure)

```text
marathi_quiz/
│
├── app.py                     # मुख्य Streamlit ॲप्लिकेशन
├── requirements.txt           # आवश्यक लायब्ररींची यादी
├── README.md                  # प्रकल्प माहिती व चालवण्याच्या सूचना
├── .env.example               # Gemini API Key उदाहरणाची फाईल
│
├── data/
│   └── questions.json         # मराठी प्रश्नांची मूळ डेटा फाईल (Source of truth)
│
└── utils/
    ├── question_loader.py     # JSON लोडिंग, प्रमाणीकरण व नॉर्मलायझेशन
    ├── quiz_engine.py         # गुण मोजणी, प्रश्न निवड व मराठी अंक रूपांतरण
    └── ai_bot.py              # Gemini AI Quiz Bot एकत्रीकरण
```

## 🚀 इन्स्टॉलेशन आणि सेटअप (Installation & Setup)

### १. डिपेंडन्सीज इन्स्टॉल करा
प्रकल्प फोल्डरमध्ये जाऊन कमांड रन करा:

```bash
pip install -r requirements.txt
```

---

## 🔑 Gemini API Key सेटअप

१. `.env.example` फाईलची कॉपी करून `.env` फाईल तयार करा:

```bash
cp .env.example .env
```

२. `.env` फाईल उघडून तुमची Google Gemini API Key प्रविष्ट करा:

```text
GEMINI_API_KEY=तुमची_API_Key_येथे_टाका
```

*(टीप: API Key नसली तरीही मुख्य प्रश्नमंजुषा, निकाल व चुकीच्या प्रश्नांचे रिव्ह्यू पूर्णपणे कार्यरत राहतात. बॉटवर मैत्रीपूर्ण सूचना दाखवली जाते व ॲप कधीही क्रॅश होत नाही.)*

---

## ▶️ ॲप्लिकेशन कसे चालवावे (How to Run)

प्रकल्प फोल्डरमध्ये खालील कमांड रन करा:

```bash
streamlit run app.py
```

किंवा:

```bash
python -m streamlit run app.py
```

ब्राउझरमध्ये ॲप्लिकेशन उघडेल (`http://localhost:8501`).

---

## 📖 प्रश्नांची फाईल (Questions Data Location)

प्रश्नांची मूळ डेटा फाईल खालील ठिकाणी ठेवली आहे:
```text
marathi_quiz/data/questions.json
```
या फाईलमध्ये इयत्ता चौथीच्या मराठी शिष्यवृत्तीचे सर्व ५१ प्रश्न, ४ पर्याय, अचूक उत्तर, घटक आणि स्पष्टीकरण समाविष्ट आहे.
